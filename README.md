## Architecture Patterns with python using FastAPI

Architectrue patterns written by Harry J.W. Percival.

Quoting `Enabling Test driven Development, Domain Driven Design and Event Driven Microservices`

I must say they really leaned on test, DDD and event handling.

I built this repository `while practicing the book` from their oficial github repo in `cosmicpython`.

I bring nothing new in this repo except

1. building it with `FastAPI` instead of `Flask`
2. Environment management with `uv`
3. Some modern syntax removing old incompatible ones.

**Note**: If you run my code, don't forget `uv sync` or `uv run fastapi dev`

- [Book](https://github.com/cosmicpython/book)
- [Code](https://github.com/cosmicpython/code)
